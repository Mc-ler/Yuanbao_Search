两个板块

研究是研究，判定是判定。

「深度研究」负责检索、去重、来源分级、来源分册和研究综述，不输出成立/不成立；「一句话查证」负责逐条断言，由 R1–R5 代码判定。两者共用检索网关和来源分级。

一句话查证 · R1–R5 字典序

规则触发条件结论
R1存在 A 级反驳，且不存在 A 级支持不成立
R2存在 A 级支持，且无 A/B 级反驳成立
R2b≥2 个独立 B+ 簇支持，无 B+ 反驳，且支持值一致成立
R3A 支持与 A 反驳并存；B+ 支持与 B+ 反驳并存；或同字段出现 ≥2 个不同值冲突（并列展示，不取平均）
R4同源簇 ≥3 条且 ≥2 个域名，断言缺少可核验细节存疑
R5其余证据不足（附已尝试路径）

「只看 A 级」：用同一组规则只跑 A 级证据，得到第二行结论。R5 时可附加模型参考意见，但明确标注「非判定」，不改变 verdict/rule_id。

深度研究 · 来源分册

  • 每个需求先由 LLM 扩写 3 条查询，再按检索结果条件触发 1 条回退查询；不再注入 subject/city，查询只使用需求派生的 focus。
  • 所有查询结果做一次全局去重（URL + 字符 5-gram + Jaccard 连通分量），同一转载簇只算一个来源。
  • 来源按域名与日期分为 A–E；A/B 为可靠来源，B/C 为降级来源。来源分册按需求、等级、域名组织。
  • 研究综述由模型生成，带 [n] 引用；引用编号由程序校验，越界会标记为 [n?]。

来源分级 A–E

级来源可核实度
A政府 / 官方公告 / 监管公示可核验
B主流媒体 / 调查报道需人工
C平台结构化页 / 百科可核验
D自媒体 / 公众号 / 资讯号需人工
EUGC / 社交平台不可核验

分级只看域名与证据日期（历史/统计按字段放宽时效）；Industry 参数只做检索过滤，不会把 UGC 升级成权威来源。

证据与截图

  • 回答阶段不把检索正文交给模型；只提供标题、域名、日期、URL 和可选页面截图。
  • 截图由无头 Chrome 打开公开页面、定位摘要并高亮截取；受登录墙/反爬影响时自动降级，不编造。
  • 截图只存内存，刷新或重启即失；不写入数据库，不落盘。

预算与停机

  • 单断言/单需求 ≤4 次检索；单次运行 ≤28 次；墙钟 ≤90 秒；单日 ≤400 次。
  • 重试必须换策略：换 Site、换 Industry、换表述；同参数重跑不算重试。
  • 一句话查证无进展即停：一轮后没有新增簇，也没有新增 A/B 级证据。

边界

  • 只做公开信息的检索与核验；不碰时政，不评价个人。
  • 不做全文抓取；证据是检索摘要、链接与页面截图，不用截图冒充完整正文。
  • 研究综述不是判定；「证据不足」是产品功能，不是失败。
  • 主路径不持久化检索结果；历史索引为旧版本只读数据。
