What it does

不是“搜一下”，
而是留下证据链。

从问题到报告，每一段都可回看：查询、域名、日期、去重簇、引用编号与判定规则。

01 / RESEARCH

深度研究

需求拆分 → 5 条查询/需求 → SearchPro → 去重 → LLM 相关性重排 → 来源分册 → 研究综述。输出综述，不输出成立/不成立。

citations + ledger 02 / VERIFY

一句话查证

断言抽取 → 定向查询 → 分批匹配 → quote 校验 → R1–R5 确定性判定。证据不足时只给非约束性参考意见，不编造结论。

R1–R5 · quote check 03 / SOURCES

来源分级与分册

A 政府/官方、B 主流媒体、C 平台结构化页、D 自媒体、E UGC。按域名与时效降级，每个需求单独成册。

A–E · freshness 04 / PRIVACY

本地优先

默认只监听 127.0.0.1；密钥只写入本地 .env；报告与截图不落盘；刷新页面即丢失，适合演示与敏感内容核验。

local · no persistence

Pipeline

一条主链路，
两种交付。

检索网关、去重、分级、引用、安全、截图全部共享；研究综述与 R1–R5 判定各自保留边界。

S1

需求 / 断言

问题拆成 1–3 个可检索需求；说法拆成独立断言。

S2

查询构造

LLM 查询 + 模板查询；精确 host 与 industry 受控。

S3

SearchPro

统一检索网关，缓存、预算、审计与零结果回退。

S4

去重 / 重排

5-gram 聚类；每需求 top 30 做 LLM 相关性重排。

S5

分级 / 报告

A–E 来源分级、引用校验、研究综述或 R1–R5。

Run locally

三步启动

PowerShell
git clone https://github.com/Mc-ler/Yuanbao_Search.git
cd Yuanbao_Search
Copy-Item .env.example .env

./.Search/Scripts/python.exe scripts/configure_keys.py yuanbao
./.Search/Scripts/python.exe scripts/configure_keys.py llm --provider deepseek
powershell -ExecutionPolicy Bypass -File scripts/restart_api.ps1

# http://127.0.0.1:8000

TIP

没有配置 Search key 时，研究和查证会返回 503，不会退回示例数据。截图需要本机 Chrome/Edge。
